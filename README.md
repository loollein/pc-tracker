# 🖥️ SysAdmin Hub (pc-tracker)

Профессиональная система инвентаризации и мониторинга компьютерной техники, сетевых устройств и принтеров для распределенных корпоративных и ведомственных сетей. Разработана с учетом специфики закрытых сетей с динамической выдачей IP-адресов по DHCP.

---

## 🚀 Основные возможности

* **📡 Умный сетевой сканер (Auto-Discovery):**
  * Автоматический опрос подсетей по пингу, ARP-таблице (определение MAC-адресов) и сканированию портов (Fingerprinting для принтеров по порту 9100/631 и ПК по 3389/22).
  * Поддержка NetBIOS-опроса (UDP 137) для точного определения реальных сетевых имен машин (`ws01`, `ws111` и т.д.) даже при отсутствии DNS-сервера.
  * **Защита от дубликатов при DHCP:** привязка существующих устройств к их MAC-адресам и именам. Если ПК меняет IP-адрес, система автоматически обновляет его в карточке без создания копий.
* **📂 Иерархическая структура:**
  * Четкое деление по уровням: Муниципальный филиал → Населенный пункт → Устройство.
  * Возможность привязки контактов, ответственных лиц и заметок к каждому филиалу и пункту.
* **🗑️ Корзина (Soft Delete):**
  * Защита от случайного удаления: удаленные устройства попадают в корзину с возможностью восстановления в один клик или окончательного стирания.
* **📜 Глобальный журнал событий (Аудит):**
  * Хронологическая лента всех изменений в инфраструктуре: авто-перемещения по подсетям, смена IP-адресов по DHCP, правки статусов и бэкапы.
* **🔥 Оперативный контроль проблем:**
  * Автоматический детектор **«Зависшего ремонта»** (устройства со статусом «На ремонте» дольше 14 дней выделяются красным).
  * Детектор **«Призраков»** (активные ПК с IP, не выходившие на связь > 30 дней).
* **🛡️ Индекс безопасности и импортозамещения:**
  * Контроль ввода ПК в домен, наличия средств защиты (СЗИ) и перехода на отечественные ОС (Astra Linux, Ред ОС, ALT Linux).
* **📊 Экспорт и бэкапы:**
  * Выгрузка отфильтрованных данных в Excel (через `ExcelJS` со стилями и автоподбором ширины колонок).
  * Создание горячего бэкапа базы данных SQLite в один клик прямо из интерфейса.

---

## 🛠️ Технологический стек

* **Бэкенд:** Node.js, Express.
* **База данных:** SQLite (через `better-sqlite3` с включенным WAL-режимом для максимальной надежности).
* **Фронтенд:** HTML5, CSS3, Vanilla JavaScript (SPA), Chart.js для графиков, SheetJS & ExcelJS для работы с таблицами.
