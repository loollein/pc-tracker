## ⚡ Быстрый старт

Чтобы клонировать репозиторий и начать использовать скрипты:

```bash
git clone https://git.example.com/username/knowledge-base.git
cd knowledge-base
chmod +x scripts/*.sh
./scripts/setup-env.sh
```

## 💡 Важные замечания

> [!NOTE]
> Все скрипты предназначены для работы в **RedOS / RHEL / CentOS**. Для других дистрибутивов могут потребоваться адаптации.

> [!WARNING]
> Перед запуском скриптов, изменяющих конфигурацию системы, обязательно создайте резервную копию важных файлов!

> [!IMPORTANT]
> Для работы некоторых скриптов требуется установленный **Python 3.8+** и **Ansible**.

### ✨ Что именно красиво отобразится в Gitea?

- **Эмодзи** (🚀, 📋, 🎯, и т.д.) – Gitea их поддерживает.
- **Списки задач** (`- [x]` и `- [ ]`) – превратятся в чекбоксы.
- **Цитаты** и **информационные блоки** (`> [!NOTE]`, `> [!WARNING]`, `> [!IMPORTANT]`) – будут выделены цветными полосами, как на GitHub.
- **Таблицы** – с выравниванием.
- **Блоки кода** с подсветкой синтаксиса (указан язык `bash`).
- **Ссылки** и **оглавление** (якоря) – работают внутри документа.
- **Изображение** (здесь не добавлено, но вы можете вставить `![alt](https://via.placeholder.com/150)`).
